# AgentOS Runtime 2.5.0rc1

**Release candidate prepared for evaluation; publication is a separate step.**

AgentOS Runtime is the reusable execution backbone for AI-enabled applications.
Hudos is the broader enterprise OS project. This RC does not include the private
Hudos application, SimonOS data, business connectors or the separate Console.

## Source and changes

The candidate starts from upstream commit
`9c9e8b7a0bb845aaeb0a4c0af97a97b7723b792b` plus reviewed documentation,
source-archive test portability, and release metadata changes. No runtime Python
implementation was changed by this packaging work.

Changes already present since v2.4.0 include store-plugin discovery, a reference
link-ingest skill, workspace-aware doctor checks, bounded webhook delivery and
explicit insecure HTTP opt-in, workspace memory routing, source-aware update
guidance, and semantic judge selection that skips unsupported CLI model bindings.
See [CHANGELOG.md](../../CHANGELOG.md) for the detailed history.

Packaging updates clarify the runtime/application boundary, supply a standalone
Core quickstart, document dependency licenses and support, and make the
checkout-detection test independent of a developer's actual `.git` directory.

## Artifacts and installation

- Python wheel: `agent_os_langgraph-2.5.0rc1-py3-none-any.whl`.
- Manifest-based source archive: includes synthetic examples, tests and bundled
  skill directories; contains no Git history or runtime data.
- SHA-256 checksums and per-file source manifest accompany the prepared artifacts.

Install the supplied local wheel with its optional API dependencies:

```bash
python -m pip install './agent_os_langgraph-2.5.0rc1-py3-none-any.whl[serve]'
python -m pip check
```

This command downloads declared dependencies; it does not imply the package is
published to PyPI. Source installation and an isolated native-tool example are
in [self-hosting](../self-hosting.md). The wheel alone does not include top-level
`skills/` or example workspaces.

## Verification and limitations

The reviewed runtime/test source passed Ruff and 955 default tests on each of
Python 3.11 and 3.12 on macOS, with 12 integration tests excluded by repository
configuration. RC packaging checks separately verify the final version, package
contents, installation, API import and the synthetic native read example.
Hosted Ubuntu CI for the final RC overlay must run when the change is submitted;
upstream base CI is not evidence for unsubmitted metadata changes.

No full enterprise workflow, provider-cost benchmark, universal egress sensor,
Windows qualification, multi-tenant isolation, automatic crash recovery or
exactly-once effects are claimed. Historical Docker/Console files remain
reference material and are not the qualified install path for this RC.

Support is [best effort](../../SUPPORT.md). See [security](../../SECURITY.md),
[known limitations](../platform/known-limitations.md), and
[dependency inventory](../dependency-inventory.md).
